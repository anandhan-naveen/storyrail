# Run 1 archive (hand-orchestrated)

The first StoryRail run, for issues #1 and #2 (Library Catalog), was orchestrated by hand in a Claude chat before the
`/storyrail` command existed. These are its agent briefs and review records, kept for reference. They use the old monorepo paths (`frontend/`, `backend/`, `tests/…`), from before the projects moved to their own repos. They are **not** used
by current runs: the live agents are in `.claude/agents/` and the orchestrator in `.claude/skills/storyrail/`.
